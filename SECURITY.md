# Security policy

Thank you for helping keep AnyHook safe.

## Reporting a vulnerability

**Do not open a public GitHub issue for security bugs.** Use one of the
private channels below instead.

### Preferred — GitHub private vulnerability reporting

Open a [private security advisory](https://github.com/gba3124/anyhook-mcp/security/advisories/new).
It stays private until we publish a fix.

### Backup — email

Send to <security@anyhook.net> with `[SECURITY]` in the subject.

## Scope

- The packages in this repository: `@anyhook/core`, `anyhook-mcp`,
  `anyhook-verify` (Apache 2.0)
- Issues in the hosted service (`anyhook.net`, `in.anyhook.net`) are also
  welcome through the same channels

## What to expect

Initial acknowledgement within **48 hours**, triage within **7 days**, and a
coordinated disclosure after the fix ships. We credit reporters in the
advisory unless you prefer to stay anonymous.
